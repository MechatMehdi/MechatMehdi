# 💫 About Me:
I am a software engineer and full-stack developer specializing in building production-grade mobile and web applications. Currently pursuing my Master's degree in Computer Science following the completion of my degree in Information Systems and Software Engineering (ISIL) at USTHB, I combine a rigorous academic foundation with extensive hands-on industry experience.<br><br>As a startup founder and lead developer of an officially incubated product, I have practical experience guiding applications from initial architectural design to deployment. My technical expertise spans backend engineering with Node.js, Express, and PostgreSQL (utilizing Redis for performance and queuing), alongside cross-platform frontend development using React, React Native, and Flutter.<br><br>Driven by a passion for efficiency, I actively leverage advanced AI workflows and integrated development tools to accelerate development pipelines, debug complex codebases, and optimize system performance. Whether architecting scalable backend systems, designing interactive mobile experiences, or leading development teams, I focus on delivering high-performance, robust, and user-centric software solutions.
